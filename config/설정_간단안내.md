# 전자책 목차 설정 간단 안내

관리할 파일: `config/books.json` (GitHub의 연필 아이콘으로 수정한 뒤 **Commit changes** 클릭)

## 기본 원칙
- `siteTitle`: 독자에게 표시되는 전자책 제목
- `readerDefaults.fit`: `auto`(모바일 세로는 전체 맞춤, 모바일 가로는 너비 맞춤, PC는 전체 맞춤), `page`(전체 맞춤), `width`(너비 맞춤)
- `readerDefaults.twoPage`: 처음 책을 열 때 두 쪽 보기 사용 여부 (`true`/`false`). 모바일 세로에서는 한 쪽 보기로 표시합니다.
- `readerDefaults.allowDownload`: 모든 PDF의 다운로드 버튼 기본 표시 여부 (`true`/`false`). 각 PDF의 `allowDownload`가 우선합니다.
- `autoDiscover: true`: 저장소의 PDF를 자동으로 찾아 목록에 추가합니다. `books`에 지정한 항목이 **먼저, 지정한 순서대로** 표시됩니다.
- `autoDiscover: false`: `books`에 적은 PDF만 표시합니다. 목차를 완전히 직접 관리할 때 추천합니다.
- `books`의 `file`: GitHub 저장소 안의 정확한 PDF 경로 (대소문자 포함). 예: `pdf/01.pdf`. 저장소 최상위에 올렸다면 `01.pdf`.
- `title`: 독자에게 표시할 제목. 파일 이름과 달라도 됩니다.
- `visible: false`: PDF를 독자용 목차에서 제외합니다. **공개 저장소의 PDF 자체는 비공개가 되지 않습니다.**
- 개별 PDF의 `allowDownload: true`: 전체 기본값과 관계없이 해당 PDF 다운로드 버튼을 보입니다. 파일 접근 권한을 통제하는 기능은 아닙니다.
- `titleRules`: 자동으로 발견된 PDF 파일명에 특정 글자가 포함되어 있으면 표시 제목을 바꿉니다. `books`에서 직접 설정한 `title`이 우선합니다.

## 목차를 직접 관리하는 예제

```json
{
  "siteTitle": "새 책 부록(전자책)",
  "readerDefaults": { "fit": "auto", "twoPage": false, "allowDownload": false },
  "autoDiscover": false,
  "books": [
    {
      "file": "pdf/01.pdf",
      "title": "첫 번째 부록",
      "visible": true,
      "allowDownload": false
    },
    {
      "file": "pdf/02.pdf",
      "title": "두 번째 부록(현재 숨김)",
      "visible": false,
      "allowDownload": false
    }
  ],
  "titleRules": []
}
```

## 자동 등록과 직접 지정 혼합
`autoDiscover`를 `true`로 두고 `books`에 일부 PDF만 나열하면 그 PDF가 목차 앞에 지정한 순서대로 표시되고 나머지는 파일명 순으로 자동 추가됩니다. `books`에 `visible: false`로 적은 PDF는 자동 등록에서도 제외됩니다.

## 수정·삭제 절차
1. 저장소에서 해당 PDF를 업로드하거나 GitHub에서 파일을 교체합니다.
2. `config/books.json`을 열고 연필 아이콘을 클릭합니다.
3. `books` 항목의 파일 경로·목차 제목·순서·표시 여부를 수정합니다.
4. GitHub의 **Commit changes**를 눌러 저장합니다.
5. GitHub Pages 배포 후 전자책 사이트를 새로고침합니다.

## 주의
- JSON에는 주석을 넣을 수 없습니다. 항목 사이에 쉼표가 필요하지만 마지막 항목 뒤에는 쉼표를 넣지 않습니다.
- PDF를 숨겨도 공개 저장소에 있으면 원본 주소로 접근할 수 있습니다. 공개하면 안 되는 파일은 올리지 마세요.
- `autoDiscover: false`에서 파일 경로가 잘못되면 목차에 나타나더라도 PDF 열기가 실패할 수 있습니다.
- 설정 문법이나 필드 값이 잘못되면 독자 화면에 오류 안내가 나타납니다. 수정 후 다시 배포해 주세요.

## 오류 메시지가 나올 때 확인할 것
- **books N번째 항목**: `books` 목록에서 위에서부터 N번째 PDF 설정을 확인합니다.
- **PDF 경로 중복**: 동일한 PDF가 두 번 등록되었는지 살핍니다. 영문 대소문자만 다른 이름도 중복으로 안내합니다.
- **PDF 파일을 찾지 못했습니다**: `file`이 저장소의 실제 폴더·파일명과 정확히 일치하는지 확인합니다. 등록한 PDF는 공개 사이트 경로에서 접근 가능한지도 확인합니다.
- **readerDefaults 관련 오류**: `fit`은 `auto`, `page`, `width` 중 하나이고 `twoPage`, `allowDownload`는 `true` 또는 `false`입니다.
- **siteTitle 오류**: 비어 있지 않은 문자열로 책 제목을 입력합니다.
- **PDF 열기 실패**: PDF 자체가 정상인지, 파일 업로드와 GitHub Pages 배포가 끝났는지 확인합니다.

**주의:** 새 PDF를 GitHub에 올린 직후에는 GitHub Pages 배포가 아직 끝나지 않아 파일 확인 오류가 일시적으로 발생할 수 있습니다. 배포가 끝난 뒤 새로고침해 주세요.
